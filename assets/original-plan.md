# 9章 代替プラン

以下は各種トラブル時の代案です。

- **RIBツアー満席・悪天候**：代替として十和田湖周遊船（遊覧船）や、休屋周辺での散策、または「十和田神社」など静かな観光に切替。湖畔ボート桟橋付近で写真撮影も可。  
- **八甲田ロープウェー運休／紅葉終了**：代わりに酸ヶ湯温泉（日帰り入浴）や八甲田山麓の「奥入瀬源流散策」、または早めに青森市内移動し「浅虫水族館」や「睡蓮沼」観光などへ。ロープウェーが使えない場合、新青森まで直行して早い列車に乗る手も。  
- **奥入瀬渓流紅葉終了**：ルートを銚子大滝や石ヶ戸周辺のみの短縮にし、時間を余剰化。渓流ではなく湖畔ドライブ（乙女の像、御鼻部山展望台など）に切り替えて紅葉散策を行う。  
- **道路通行止め・凍結**：レンタカーならチェーン携行、公共は早いバス便に切り替え。国道103号（八甲田）や奥入瀬沿いの冬期閉鎖情報に注意。代案として国道7号経由で青森へ戻るルート検討も。  
- **バス運行中止・本数不足**：公共移動不可ならタクシー利用。青森空港〜奥入瀬の直通や貸切タクシー（県営相乗り）情報も検討。八甲田地区なら観光タクシー（八郎太郎号等）も利用可。  
- **宿予約不可**：休屋・十和田湖エリア満室時は十和田市街地（小坂市や鹿角市方面の温泉宿）に切り替え、代わりに最終日の移動計画を組替える案。
